Level 09 · Assembling f

Round Function II: P-Box & the Round

One last permutation spreads the S-box outputs, then the whole round function plugs into the Feistel step.

★ +100 XP Badge: Diffusion Master Not yet complete
Briefing

The S-boxes produce 32 bits. The P permutation rearranges those 32 bits so that the four output bits of any single S-box are scattered across the next round's input. This diffusion means a tiny input change ripples widely after a few rounds.

Now the full round function is complete:

f(R, K) = P( S( E(R) XOR K ) )

And the round itself:

newR = L XOR f(R, K)
newL = R

That is one round of DES. Do it 16 times, swapping each round, and you have encrypted a block.

Key idea f = P(S(E(R) XOR K)). Expansion, key mixing, non-linear substitution, then diffusion.

Python · solution
def f(R, subkey):
    x = mix_with_key(expand(R), subkey)   # 48 bits
    s = substitute(x)                     # 32 bits
    return permute(s, P)                  # 32 bits

def des_round(L, R, subkey):
    return R, xor(L, f(R, subkey))
