Briefing

The full encryption, start to finish:

  1. Apply IP to the 64-bit plaintext.
  2. Split into L0 and R0 (32 bits each).
  3. Generate the 16 subkeys from the key.
  4. For i = 1..16: Li = Ri-1 ; Ri = Li-1 XOR f(Ri-1, Ki).
  5. Combine the halves swapped: R16 + L16.
  6. Apply FP to get the 64-bit ciphertext.

The classic test vector: key 133457799BBCDFF1, plaintext 0123456789ABCDEF must give ciphertext 85E813540F0AB405. If your code produces that, it is correct.

Debug tip Wrong output? Check, in order: (1) 1-based vs 0-based indexing, (2) the final half-swap before FP, (3) whether you used all 16 subkeys.

def des_encrypt(block_bits, key_bits):
    b = initial_permutation(block_bits)
    L, R = b[:32], b[32:]
    for K in key_schedule(key_bits):
        L, R = des_round(L, R, K)
    return final_permutation(R + L)   # note the swap: R then L

Checkpoint
1. What order are the halves in just before the final permutation?
The halves are combined as R16 + L16, i.e. swapped, before FP.
2. How many subkeys are used in a full encryption?
One subkey per round, so all 16 are used.
3. The official test vector plaintext 0123456789ABCDEF with key 133457799BBCDFF1 gives...
